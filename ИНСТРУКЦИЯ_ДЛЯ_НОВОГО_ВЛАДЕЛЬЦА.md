# Инструкция для нового владельца проекта

## ⚠️ ВАЖНО: Вся конфиденциальная информация удалена

Из проекта удалены все токены, приватные ключи, API ключи и другая секретная информация. Вам нужно настроить всё с нуля.

## 🚀 Быстрый старт

### 1. Скопируйте шаблон конфигурации

```bash
cp .env.example .env
```

### 2. Заполните .env файл

Откройте `.env` и замените все значения на свои:

#### Обязательные параметры:

**Telegram бот:**
- Создайте бота через [@BotFather](https://t.me/botfather)
- Скопируйте токен в `TELEGRAM_BOT_TOKEN`

**Django секретный ключ:**
```python
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```
Скопируйте результат в `SECRET_KEY`

**Домен:**
- Замените `your-domain.com` на ваш домен в `WEBAPP_URL`

**Кошельки для депозитов:**
- TRON (TRC-20): создайте кошелек в TronLink
- BSC (BEP-20): создайте кошелек в MetaMask
- TON: создайте кошелек в TonKeeper

Сохраните адреса и приватные ключи в `.env`:
- `DEPOSIT_ADDRESS_TRC20` и `TRON_PRIVATE_KEY`
- `DEPOSIT_ADDRESS_BSC` и `BSC_PRIVATE_KEY`
- `DEPOSIT_ADDRESS_TON` и `WITHDRAW_TON_MNEMONIC`

**API ключи:**
- Moralis: https://moralis.io/ → `MORALIS_API_KEY`
- Infura: https://infura.io/ → `INFURA_API_KEY`
- BscScan: https://bscscan.com/apis → `BSC_API_KEY`
- TON: https://toncenter.com/ → `TON_API_KEY`
- WalletConnect: https://cloud.walletconnect.com/ → `WALLETCONNECT_PROJECT_ID`

### 3. Обновите домен в файлах

Замените `your-domain.com` на ваш домен в:

1. `webapp/webapp/settings.py`:
   - `ALLOWED_HOSTS`
   - `CSRF_TRUSTED_ORIGINS`
   - `CORS_ORIGIN_WHITELIST`

2. `proxy/nginx/conf_prod/nginx.conf`:
   - `server_name`
   - Пути к SSL сертификатам

3. `docker-compose.prod.yml`:
   - `WEBAPP_URL` в секции telegram_bot

### 4. Настройте Moralis API в frontend

Отредактируйте `webapp/core/static/scripts/moralis-api.js`:

```javascript
class MoralisAPI {
    constructor() {
        this.apiKey = 'ВАШ_MORALIS_API_KEY';
        // ...
    }
}
```

### 5. Установите SSL сертификаты

```bash
docker-compose -f docker-compose.prod.yml run --rm certbot certonly \
  --webroot --webroot-path /var/www/certbot/ \
  -d ваш-домен.com
```

### 6. Запустите проект

```bash
# Соберите и запустите контейнеры
docker-compose -f docker-compose.prod.yml up -d --build

# Примените миграции базы данных
docker-compose -f docker-compose.prod.yml run --rm webapp python manage.py migrate

# Создайте суперпользователя
docker-compose -f docker-compose.prod.yml run --rm webapp python manage.py createsuperuser

# Проверьте логи
docker-compose -f docker-compose.prod.yml logs -f
```

## 🔒 Безопасность

### ОБЯЗАТЕЛЬНО:
- ✅ Используйте уникальные пароли и ключи
- ✅ Храните приватные ключи в безопасном месте
- ✅ Используйте разные кошельки для тестов и продакшена
- ✅ Регулярно делайте бэкапы
- ✅ Включите 2FA на всех сервисах
- ✅ Мониторьте балансы кошельков

### НИКОГДА:
- ❌ Не коммитьте .env файлы в git
- ❌ Не делитесь приватными ключами
- ❌ Не используйте тестовые кошельки в продакшене
- ❌ Не храните большие суммы на горячих кошельках
- ❌ Не используйте одинаковые пароли

   - Систему ставок
   - Telegram бота
