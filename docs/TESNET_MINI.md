## TESNET_MINI.md — мини‑чеклист для теста 💡

Цель: **быстро проверить, что всё живо**, не углубляясь в тонкости девопса.  
Тебе нужен только **Windows + браузер + терминал с доступом к серверу**.

---

### 0. Предварительные условия

Перед началом убедись, что уже сделано (один раз):

- На сервере настроен проект `widepiper` (тот, где мы сейчас работаем).
- Есть виртуальное окружение `.venv` и зависимости (Poetry уже прогоняли).
- Nginx проксирует `tg.ma8ka.com` на бекенд (мы это уже настроили).

Если это тот же сервер, где мы недавно всё поднимали — всё ОК 👍

---

### 1. Подготовить тестовое окружение (env) 🧾

1. Зайди на сервер по SSH (через любой SSH‑клиент для Windows: PuTTY, MobaXterm, Windows Terminal):

   ```bash
   ssh user@your-server-ip
   cd /home/jk/space/widepiper
   ```

2. Скопируй шаблон `.env` (если ещё не скопирован):

   ```bash
   cp .env.example .env
   ```

3. Открой `.env` в любом редакторе на сервере:

   ```bash
   nano .env
   ```

   И заполни минимум:

   - `SECRET_KEY` — сгенерировать можно командой:

     ```bash
     python3 - << \"PY\"
     from django.core.management.utils import get_random_secret_key
     print(get_random_secret_key())
     PY
     ```

   - `WEBAPP_URL=https://tg.ma8ka.com`
   - `TELEGRAM_BOT_TOKEN=...` (из @BotFather)
   - Тестовые кошельки и API‑ключи (можно взять маленькие, только для проверки):
     - `APP_WALLET`, `APP_WALLET_PRIVATE_KEY`
     - `DEPOSIT_ADDRESS_BSC`, `BSC_PRIVATE_KEY` (для mini‑теста можно ограничиться BSC)
     - `MORALIS_API_KEY`, `BSC_API_KEY`, `BSC_RPC_URL` (провайдеры дадут в личном кабинете)

💡 Если уже есть рабочий `.env`, этот шаг можно пропустить.

---

### 2. Запустить всё одной командой 🚀

1. На сервере (в каталоге проекта):

   ```bash
   cd /home/jk/space/widepiper
   bash scripts/start-prod-no-docker.sh
   ```

2. Подожди 10–30 секунд и проверь, что бекенд поднялся:

   ```bash
   curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8001/
   ```

   Если видишь `200` или `302` — отлично.

3. В браузере на Windows открой:

   - `https://tg.ma8ka.com`

Если страница открылась — можно идти дальше.

### 3. Мини‑тест через браузер 🧪

Сейчас всё делаем только из браузера (Chrome/Edge/Firefox на Windows).

1. **Регистрация и вход**
   - Зайди на `https://tg.ma8ka.com`.
   - Нажми «Sign Up» и создай тестового пользователя.
   - Разлогинься и залогинься снова — убедись, что логин работает.

2. **Проверка профиля**
   - Открой страницу профиля (обычно `/profile/` или кнопка «Profile» в меню).
   - Убедись, что:
     - отображается имя пользователя;
     - есть сгенерированный внутренний кошелёк (BSC‑адрес);
     - баланс USDT равен `0.00` (или около того).

3. **Игровой мини‑тест (без блокчейна)**
   - Открой страницу игр (`/games/` или «Games» в навигации).
   - Запусти Flappy Bird, поиграй, чтобы что‑то выиграть.
   - После окончания игры проверь, что:
     - всплывает сумма «Earned … USDT»;
     - если перейти в профиль, баланс USDT увеличился.

Этот шаг **не трогает блокчейн**, но показывает, что webapp + API живы ✅

### 4. Мини‑депозит и баланс (BSC testnet/маленький объём) 💸

Если хочешь проверить **настоящее зачисление с сети** — делаем один небольшой тест:

1. Убедись, что в `.env` заполнены BSC‑поля (см. шаг 1).
2. На Windows открой кошелёк (MetaMask или др.) с **небольшим количеством USDT на BSC/BSC testnet**.
3. В браузере:
   - Открой страницу «Deposit» или раздел, где показаны депозитные адреса.
   - Найди адрес для BSC (`DEPOSIT_ADDRESS_BSC` / BSC network).
4. Отправь **очень маленькую сумму** USDT (например `0.5`) на этот адрес.
5. Подожди 1–5 минут (зависит от сети и лимита подтверждений).
6. Проверяй:
   - Страницу профиля — баланс USDT должен увеличиться.
   - (Опционально) вкладку «Deposit history» — транзакция должна появиться.

Если что‑то не работает — проще всего смотреть логи на сервере:

```bash
cd /home/jk/space/widepiper
tail -n 50 logs/deposit_monitor.log
```

### 5. Мини‑ставка и расчёт блока 🧮

Для супер‑мини теста можно сделать **одну маленькую ставку**, не обязательно ждать реальных цен токенов:

1. Убедись, что у пользователя **есть баланс USDT** (из игры или депозита).
2. В браузере:
   - Перейди на страницу ставок (`/bet/` или «Bet»).
   - Создай ставку:
     - размер (например `0.1` USDT),
     - процент (любой).
3. Подожди >10 минут (один цикл bet_manager) или чуть больше.
4. Проверь:
   - в UI список ставок: у ставки должен появиться статус (выиграл/проиграл);
   - баланс USDT должен измениться (для выигрышной ставки — увеличиться).

Если хочется увидеть, что реально работает фон:

```bash
cd /home/jk/space/widepiper
tail -n 50 logs/bet_manager.log
```

Должны быть строки вида `Processing X active bets`, `Winners: ..., Losers: ...`.

### 6. Telegram Mini App (по желанию) 📱

Этот шаг можно пропустить, но он простой:

1. Убедись, что в `.env` выставлен корректный `TELEGRAM_BOT_TOKEN` и `WEBAPP_URL=https://tg.ma8ka.com/`.
2. В Telegram (на телефоне/десктопе):
   - Найди своего бота (@имя_бота).
   - Отправь `/start` или `/app`.
   - Нажми на кнопку «Приложение» — откроется Mini App.
3. Внутри Mini App:
   - залогинься,
   - посмотри баланс,
   - при желании сделай маленькую ставку или сыграй в игру.

Если Mini App открывается и работает аналогично веб‑версии — отлично 🎉

Когда закончишь мини‑тест:

2. Проверить, что процессы не висят (по желанию):

   ```bash
   ps aux | grep -E "gunicorn|bet_manager|monitor_deposits|telegram_bot" | grep -v grep
   ```

На этом mini‑тест завершён ✅
